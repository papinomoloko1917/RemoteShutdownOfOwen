## Как использовать

1. На компьютере пользователя **сохранить текущую схему в Owen Logic через Ctrl+S**: `SHAOP2_PR103_MAIN_SIM_ONLY.owle`. На скриншотах вкладка была помечена «Схема*» — не считать, что последние изменения уже записаны в файл. По возможности сохранить отдельную резервную копию FBD.
2. В уже открытой симуляции t=8,0 с продолжить с **T30** из `PROJECT_STATUS.md` §16.7. Не менять одновременно heartbeat и признак обмена. Если симуляция закрыта, восстановить лишь предпосылки T30; не повторять всё ранее проверенное ради формального «PASS».
3. Когда будете вручную переносить документы в Git, сначала посмотрите отличия от локальных `AI_HANDOFF.md`/`PROJECT_STATUS.md`. Копируйте **оба обновлённых `.md` вместе**, а текущий `.owle` — только после сохранения в Owen Logic. Пример ручной проверки: `git status`, `git diff -- AI_HANDOFF.md PROJECT_STATUS.md`, `git diff --name-only`. Не добавляйте непроверенные autosave автоматически.
4. **Ничего не отправлено в GitHub этим пакетом.** Никакая новая программная схема `.owle` в архив не добавлена и не верифицирована; файл из GitHub на момент сверки описывал старую версию.
