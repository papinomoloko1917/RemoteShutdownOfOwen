# RemoteShutdownOfOwen V2 — актуальные документы на 12.11.2026

**Основа:** GitHub `main`, commit `d32dfd875d4cec1f79a8740a736e5c08de99a752` (только чтение). **Статус:** `DESIGN / NOT IMPLEMENTED / SIM_ONLY`. Эти документы — самостоятельный актуальный пакет решения от 12.11.2026, а не утверждённая рабочая программа.

**Что согласовано:** после ремонта оптики ПР103 **сохраняет санкционированный режим LOCAL**. Возврат в REMOTE возможен только после нового сознательного действия персонала, проверки актуальной SB1 и выполнения условий перехода. Возврат Modbus OK, новый HB или старый STOP=0 не сбрасывают защитную блокировку.

**Что не согласовано:** использование повторного нажатия SB3 в качестве команды возврата, критерия достоверности SB1 после рестарта/обрыва, времен, поведения при новой SB1=1 во время LOCAL. Подробности — `docs/architecture/OPEN_DECISIONS_CURRENT.md`.

**Новое первоисточник:** руководство ОВЕН «Owen Logic (версия 3.3). Руководство пользователя», версия 2.12 (09.2026), 325 стр.; неизменённый PDF в `references/owen/manuals/rp_owen_logic.pdf`.

**Важное:** это новый готовый документальный снимок, который можно добавить в репозиторий без изменения исторических файлов. Первичные документы `AI_HANDOFF.md`, `PROJECT_STATUS.md` §§1–22, `README_CHECKPOINT.md` ред. 11, старые `.owle`, архив и результаты испытаний сохраняются неизменными в существующем `main`. В данный пакет не включены их переписанные копии.
