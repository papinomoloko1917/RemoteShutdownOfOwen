# Исходные требования и схема

По `docs/reference/FILE_MIGRATION_PLAN.md` сюда пользователь переносит три ТЗ DOCX (редакции 4, 5 и 6) и `СДУО-СС-01_Схема_структурная_редакция_1.pdf`. ТЗ ред. 6 имеет статус **ПРОЕКТ для согласования**, не подписано; оно ссылается на структурную схему ред. 2, которой нет в исходной ветке. Не переименовывать ред. 1 в ред. 2 и не считать их взаимозаменяемыми.

Документы в папке — исходные доказательства требований, не готовая рабочая электрическая схема.
