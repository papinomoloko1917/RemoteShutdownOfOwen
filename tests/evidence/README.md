# Свидетельства испытаний

В этой директории **нет** автоматически созданных доказательств из прошлого чата. `PROJECT_STATUS.md` §19.10 и §20.9 содержат имена/описания кадров из переписки, но файлы скриншотов не были включены в исходный Git.

Для новых SIM-тестов сохранять скриншоты FBD и наблюдаемого диагностического сетевого выхода с тест-ID, датой, версией файла, входными сигналами и результатом. Не называть результат `PASS-SIM`, пока наблюдение не подтверждено.
