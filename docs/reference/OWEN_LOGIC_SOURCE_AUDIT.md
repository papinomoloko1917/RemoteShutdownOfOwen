# OWEN FIRST — Owen Logic 3.3, руководство пользователя v2.12, сентябрь 2026

**Официальный источник пользователя:** `references/owen/manuals/rp_owen_logic.pdf`, «Owen Logic (версия 3.3). Руководство пользователя», редакция 2.12 от 09.2026 (325 страниц). Данные ниже — функции среды, а не сертифицированный алгоритм отключения ЩАО. Рабочая версия среды у проекта — Owen Logic 3.3.378.0; версия руководства ≠ идентификатор установленной сборки.

**Ограничения источника:** не указан готовый автомат `LOCAL/RECOVERY_WAIT`, не доказана невозможность replay после рестарта, не выведены минимальная длительность SB1 или штатная сертифицированная функция SIL/PL. Все эти вопросы относятся к требованиям ТЗ и инженерному проектированию, не к фактам ОВЕН.

**Примеры ОВЕН:** `examples/owen/avr_2inputs/2 ввода на общую шину.owle` (иная модификация ПР205, Owen Logic 2.7.350), `Counter.owl` (ПР200, старая версия) не переносить в FBD 3.3 без проверки совместимости. Сведения сообщества не использованы как техническое основание данного дополнения.
