## 2. Назначение и технические свойства — подтверждено ОВЕН

- РЭ §1, стр. 8: измерительный модуль трёхфазной электрической сети; 8 DI, 2 релейных DO. Наш проект использует **измерения**, но не поручает МЭ210 управление K1, ЩАО или восстановлением питания.
- РЭ §2.1, стр. 9–11: питание **10–48 В DC**, потребление не более **8 Вт**; номинальное фазное 230 В, межфазное 400 В; обновление измеренных значений **15 мс**, частота получения измеренных значений **65 Гц** (не равно гарантированному времени доставки в ПР103).
- РЭ §2.1, стр. 10: основная приведённая погрешность фазного напряжения **0,2 %** указана только для `0,05×Uном ≤ U ≤ 1,5×Uном`; при 230 В нижняя граница **11,5 В**. Нельзя переносить нормативную точность 0,2 % к нулю.
- РЭ §5.5, стр. 18–20: подключение измерительных фаз и нейтрали требует штатной схемы; физическое подключение допустимо только после отдельного проектирования и допуска специалиста.
- РЭ §6.5, стр. 28: **Modbus TCP Slave**, порт **502**, до **3 одновременных Master**, также Modbus RTU Slave; Ethernet и RS-485 допускают одновременный опрос. Операции чтения: FC03/FC04, записи FC06/FC16. Для нашей задачи нужны **только чтения**.
- РЭ §6.5.1, стр. 28: порядок **байт старшим вперёд**, **16-битных регистров младшим вперёд** (важно для FLOAT32/UINT32).
- РЭ §6.6.7, стр. 44: при включённой внутренней фильтрации данные усредняются за **1 секунду**. Полная задержка определяется ещё и периодом Master, сетевыми тайм-аутами и логикой.
- РЭ §6.2, стр. 25, §8.2, стр. 56: диагностический индикатор и батарейка **CR2032 для часов RTC**, а не для продолжения измерений и сетевого обмена при потере питания. Питание только USB — режим конфигурирования без работающих I/O.
- РЭ §5.8, стр. 21–22: встроенный Ethernet Bypass между **медными портами**, при этом модуль без питания не измеряет напряжение.

## 3. Карта Modbus МЭ210-701 — подтверждено ОВЕН

РЭ **таблица 6.5, стр. 30–31**. Адреса **DEC** именно **в адресном пространстве МЭ210**, а не ПР205/ПР103. Следующие значения предназначены для **чтения**, не для записи.

| Параметр | Адрес DEC | HEX | Тип | Регистров (16 бит) |
|---|---:|---|---|---:|
| Действующее напряжение фазы A | **5240** | `0x1478` | `FLOAT32` | 2 |
| Действующее напряжение фазы B | **5242** | `0x147A` | `FLOAT32` | 2 |
| Действующее напряжение фазы C | **5244** | `0x147C` | `FLOAT32` | 2 |
| Статус ошибок измерений | **5340** | `0x14DC` | `UINT32` | 2 |
| Напряжение батареи RTC (не для контроля фаз) | 801 | `0x0321` | `UINT16`, мВ | 1 |

**Инженерное предложение (ещё НЕ конфигурация):** в ПР103 создать **отдельное** Master-устройство `ME210` с IP-адресом, назначенным проектом (не предполагать адрес 192.168.1.99); один FC03 с DEC 5240 / длиной **6** регистров для A+B+C и один FC03 с DEC 5340 / длиной **2** регистра для диагностической маски. Оба запроса должны относиться к одному устройству. Проверить в Owen Logic 3.3 правильное декодирование 32-битных значений, границы группировки, адресацию DEC/offset, таймауты и обработку ошибок. Само объединение 6 регистров не доказывает синхронность снимка измерений и маски ошибок, читаемых отдельным запросом.

`PR205_KPP` и `ME210` — **разные Modbus Slave**; их карты DEC независимы. Не добавлять FC03 для МЭ210 в архивные `.owle`.

## 4. Диагностика измерительных каналов — подтверждено ОВЕН

РЭ **§6.6.10, таблица 6.12, стр. 45**: статус — битовая маска; `UINT32` расположен с адреса **5340**.

| Бит маски | Значение по РЭ |
|---:|---|
| **0** | Ошибка связи с измерительным модулем (внутренняя диагностика) |
| **1** | Нет напряжения на фазе A |
| **2** | Нет напряжения на фазе B |
| **3** | Нет напряжения на фазе C |
| 4–6 | Нет нагрузки на фазах A–C |
| 7–9 | Перенапряжение фаз A–C (в РЭ указан порог 410 В) |
| 10–12 | Перегрузка фаз A–C по току |
| **13** | Ошибка калибровки |

**Ограничение:** РЭ не даёт подтверждённого численного порога срабатывания статусов «нет напряжения» по битам 1–3. Не назначать этим битам произвольное значение, например «строго менее 5 В». `mask=0` **не означает** отсутствия напряжения: напротив, признаки «нет напряжения» при соответствующих условиях находятся в **установленных** битах 1–3. Отсутствие ответа Modbus — **не** нулевое напряжение.

## 5. Модель достоверности и применение в V2 — ПРЕДЛОЖЕНИЕ AI

**Разделить три понятия:**

1. `ME210_COMM_OK` — штатный статус обмена ПР103 с **отдельным Slave МЭ210** (не подменять статусом ПР205 или индикацией Ethernet).
2. `ME210_DATA_VALID` — текущие (не просроченные) корректно прочитанные и согласованно интерпретированные A/B/C + диагностика, без запрещающих ошибок; технические критерии достоверности и доступности регистров **ещё не согласованы**.
3. `THREE_PHASES_LOW` — **условный технологический** результат сравнения A, B, C с тремя согласованными порогами при `ME210_DATA_VALID=TRUE`, а не подтверждение электробезопасности.

При старте, перезапуске ПР103/МЭ210, ошибке чтения, потере связи, диагностической ошибке, некорректных FLOAT32 (`NaN`, бесконечность, диапазон вне физических границ) или старом значении в памяти — `ME210_DATA_VALID=FALSE`, состояние фаз **UNKNOWN**, не «0 В». Не использовать зафиксированное старое нулевое значение после потери связи. Режим сброса подтверждения и максимальный возраст данных — отдельные проектные параметры.

**Индикация HL2:** исходное требование об индикации «отключение подтверждено» по трём фазам сохраняется как проектное, но его необходимо строго ограничить смыслом «условие контроля напряжения по измерениям достигнуто». Результат МЭ210, обычный Modbus и HL2 **не являются сертифицированным доказательством отсутствия опасного напряжения** для допуска к работам на электроустановке. При `UNKNOWN` HL2 не может утверждать измеренное отсутствие напряжения; способ отдельной индикации неисправности измерения остаётся на согласовании.

Не влиять данными МЭ210 на снятие SB1, на выход из LOCAL или на разрешение опасного восстановления питания, пока это не предусмотрено утверждёнными требованиями и оценкой риска. Измерение напряжения после АВР требует подтверждения **фактической точки измерения** относительно всех источников (включая ДГУ), нейтрали и трансформаторов.

## 6. Что необходимо согласовать до программирования FBD (D-09)

- Электрическая схема точек измерения A/B/C/N и измерительных трансформаторов (если используются); влияние ДГУ/АВР, независимая проверка монтажной документации специалистом.
- Порог/гистерезис/выдержка **по каждой фазе**, допустимость встроенного фильтра 1 с и общая задержка индикации; точность вблизи нуля не подтверждена нормой `0,2 %`.
- Семантика диагностических битов 1–3: проверить порог/задержку через ОВЕН или на изолированном стенде, не подменять нормативной проверкой напряжения.
- Условия `ME210_DATA_VALID`: возраст набора регистров, статус Slave, диагностика, последовательное чтение, типы FLOAT32 и UINT32, ошибки ответа/тайм-ауты.
- Статус индикации `UNKNOWN` при отказе измерителя, восстановлении питания, некорректных и устаревших данных.
- Параметры IP/периода опроса и версия прошивки **физического МЭ210** — пока `OPEN`.

## 7. Проектная матрица проверки (только `SIM_ONLY`, без сети и физических выходов)

| ID | Подставляемые данные | Ожидаемая логика (к утверждению) |
|---|---|---|
| `V2-ME-S01` | A/B/C корректны и ниже отдельных порогов | `THREE_PHASES_LOW=1` только при `ME210_DATA_VALID=1` |
| `V2-ME-S02` | Одна фаза выше порога | `THREE_PHASES_LOW=0` |
| `V2-ME-S03` | Все три «0 В», но Modbus потерян | `ME210_DATA_VALID=0`, результат `UNKNOWN`, HL2 не подтверждает |
| `V2-ME-S04` | Ошибка калибровки / диагностический бит 0 | Запрет подтверждения; код причины ошибки отдельно |
| `V2-ME-S05` | Рестарт ПР103/МЭ210, старые 0 В сохранены | `UNKNOWN` до нового подтверждённого чтения |
| `V2-ME-S06` | Ошибка порядка 16-битных регистров FLOAT32 / `NaN` | Ошибка данных, не допускать подтверждения |

Все строки — `NOT RUN / DESIGN ONLY`, не PASS. Реальные Modbus TCP, значения регистров, тайминги и аналоговые измерения требуют отдельного изолированного стенда и разрешения на электрические испытания.
