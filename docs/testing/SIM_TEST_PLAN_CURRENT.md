# SIM_TEST_PLAN_V2 — дополнение D-02 (12.11.2026)

**Выполнение тестов:** `NOT RUN / BLOCKED`. Среда Owen Logic 3.3.378.0, время SIM-цикла 100 мс. Проверяются абстрактные логические сигналы; без физических Q, K1, SB2/ЩАО, измерений МЭ210 и реальных FC03/FC06.

| ID | Сценарий | Критерий | Статус |
|---|---|---|---|
| V2-SIM-01 | Старт ПР103, в памяти старый STOP=0 | INIT_UNTRUSTED, защитный логический STOP, никакого авто-LOCAL | NOT RUN |
| V2-SIM-02/03 | Нажатие/отпускание SB1 при непрерывном REMOTE | STOP=1/0 соответственно, только при достоверном текущем сообщении и отсутствии lock | BLOCKED D-01 |
| V2-SIM-04/05 | Потеря оптики при прежней SB1=0/1 | LOSS_LOCK, STOP=1, нет снятия защиты из старого STOP | NOT RUN |
| V2-SIM-06/07 | Новая санкционированная SB3, LOCAL, SB1 меняется без оптики | LOCAL остаётся; новое действие SB1 не поступает | BLOCKED D-03 |
| V2-SIM-08 | SB3 удержана до старта | Не создавать новое разрешение | NOT RUN |
| V2-SIM-09 | При восстановлении доказанно текущая SB1=1 | Приоритет STOP=1; режим уточнить | BLOCKED D-01/D-15 |
| V2-SIM-10 / T35 | LOCAL+LOCK, старый STOP=0, новый HB и Modbus OK | **LOCAL и LOCK НЕ сбрасываются**, никакого автоматического перехода | NOT RUN; исторический T35 FAIL-SIM |
| V2-SIM-11/16 | LOCAL, оптика исправлена, SB1=0, нет нового действия персонала | **Остаётся LOCAL**; автоматический вход в RECOVERY_WAIT запрещён | NOT RUN |
| V2-SIM-17 | Новая санкция возврата + доказанно текущая SB1=0 + устойчивая связь | Только тогда возможен контролируемый возврат, без вывода о фактическом пуске | BLOCKED D-01/D-03/D-04 |
| V2-SIM-18 | Санкция возврата, но STOP=0 старый/не доказана свежесть | Нельзя завершить LOCAL и снять LOCK | BLOCKED D-01/D-04 |
| V2-SIM-19 | Удержанная/дребезжащая SB3 при старте или попытке возврата | Нет ложного нового действия | BLOCKED D-03 |
| V2-SIM-20 | Повторный обрыв во время санкционированного возврата | Режим/STOP по согласованному приоритету, не по старой санкции | BLOCKED D-15 |
| V2-SIM-12/13 | Рестарт ПР205/ПР103, старый N/ACK, переполнение | Старый STOP=0 не доказывает разрешение | BLOCKED D-01/D-04 |
| V2-SIM-14 | Потеря питания любого КСН | Потеря доверия/защитная реакция | NOT RUN |
| V2-ME-S01…06 | Три фазы, ошибка одной фазы, пропадание МЭ210, ошибочная маска, NaN | LOW только по достоверным данным A/B/C; иначе UNKNOWN, HL2 не подтверждает | NOT RUN, D-09 OPEN |

**Режим записи результата:** для каждого теста указать SHA `.owle`, версию среды, начальные значения, шаги, значения FBD/сетевого диагностического выхода, OBSERVED и PASS-SIM/FAIL-SIM/BLOCKED. Не записывать PASS-SIM по ожидаемым значениям до исполнения.

**OWEN FIRST:** Owen Logic 3.3 v2.12, §4.5, стр. 59–62 (SIM и ограничение ветвей); §7.2.1, стр. 163–165 (триггеры); §5.3.2.1, стр. 121–123 (Master).
