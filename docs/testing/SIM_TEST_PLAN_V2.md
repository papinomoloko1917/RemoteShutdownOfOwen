# SIM-тесты для новой реализации V2

**АКТУАЛИЗАЦИЯ 13.11.2026 — ПЛАН ЧАСТИЧНО ВЫПОЛНЕН ТОЛЬКО ДЛЯ Unit-SIM ПР103.** Owen Logic 3.3.378.0, цикл 100 мс, локальный ST/FBD `V2_MODE_CORE REV2`; искусственные I1–I6/FI1, без реального Modbus, Q/К1/ЩАО/МЭ210. Ниже таблица `V2-SIM-01…21` — исходная широкая программа регрессионных/интеграционных испытаний; её прежние NOT RUN не следует автоматически заменять результатами узкого Unit-SIM.

**Канонический протокол наблюдений и конкретная матрица V2-MODE-01…11:** [`V2_SIM_RESULTS_2026-11-13.md`](V2_SIM_RESULTS_2026-11-13.md). Основная последовательность 0→1→2→3→4→1 и N-01…N-03 наблюдались; N-04a подтверждён только по удержанному старому I6; N-04b требует отдельного итогового кадра; N-05b (удержанная SB3 при рестарте) NOT TESTED. D-01/D-04 OPEN, исторические T35/P04-02 FAIL-SIM. Не писать «все V2-MODE PASS». Для каждого следующего теста фиксировать конкретный файл/хеш, шаги, наблюдения и доказательства.

## Дополнительные целевые SIM-сценарии МЭ210-701 (12.11.2026)

**Все `NOT RUN / DESIGN ONLY`.** Это проверка только логики на искусственно заданных величинах без физического МЭ210, без фактической сети и без задействования выходов Q/K1/ЩАО. См. `docs/reference/ME210_701_OWEN_SOURCE_AUDIT.md`.

| ID | Данные | Запрещённая ошибка / ожидаемое условие |
|---|---|---|
| `V2-ME-S01` | Три действительных значения ниже утверждённых порогов | Условный признак LOW лишь при `ME210_DATA_VALID=TRUE` |
| `V2-ME-S02` | Напряжение хотя бы одной фазы выше порога | LOW не утверждается |
| `V2-ME-S03` | Старые «0 В», Modbus потерян | `UNKNOWN`, HL2 не подтверждает |
| `V2-ME-S04` | Диагностическая ошибка измерителя (бит 0 / 13) | `UNKNOWN`, HL2 не подтверждает |
| `V2-ME-S05` | Рестарт ПР103/МЭ210, сохранены старые нули | До нового корректного чтения `UNKNOWN` |
| `V2-ME-S06` | Ошибка порядка слов/нечисловой FLOAT32 | Неверные данные не подтверждают отключение |

Дополнительно после создания конфигурации на **изолированном** стенде (с отдельным разрешением): проверить реальные адреса DEC и 32-битные типы, задержки/фильтр, смысл битов «нет напряжения», потерю питания и конфигурацию сети. **Стендовые проверки не являются SIM и сейчас не проводились.**

## Unit-SIM автомата V2-A (все NOT RUN)

**Признаки `COMM_OK_SIM`/`SB1_VALID_SIM`/`SB1_STOP_SIM` искусственно задаются испытателем. PASS такого сценария не закрывает D-01/D-04, T35/P04-02 или реальные Modbus/аппаратные проверки.**

| ID | Сценарий | Ожидаемое поведение | Статус |
|---|---|---|---|
| V2-MODE-01 | Рестарт ПР103, старый STOP=0, SB3 удержана | INIT_UNTRUSTED, STOP=1, нет ложной санкции | NOT RUN |
| V2-MODE-02 | REMOTE, SB1_VALID_SIM=1, SB1=1→0, LOCK=0 | STOP=1→0 лишь при синтетическом доверии | NOT RUN |
| V2-MODE-03 | REMOTE, потеря связи/достоверности | LOSS_LOCK, STOP=1 | NOT RUN |
| V2-MODE-04 | LOSS_LOCK, новое SB3 после отпускания и санкции | LOCAL, только одно разрешение | NOT RUN |
| V2-MODE-05 | LOCAL, связь восстановлена, SB1=0, нет второго SB3 | LOCAL, без RECOVERY_WAIT/сброса LOCK | NOT RUN |
| V2-MODE-06 | LOCAL, SB3 отпущена и нажата вторично при восстановленной связи | RECOVERY_WAIT | NOT RUN |

**Граница утверждения:** `APPROVED FOR SIM DESIGN / NOT IMPLEMENTED / NOT TESTED / HW NOT APPROVED`. **D-01/D-04 OPEN:** действительная свежесть SB1 при незамеченных рестартах, replay/wrap/старых данных не доказана; HB и Modbus status недостаточны. Для SIM автомата допускаются *искусственно заданные* валидные входы, но не утверждение реального обмена. Времена D-13/D-14, МЭ210 D-09, аппаратные D-05–D-12 OPEN. ТЗ ред. 6 — ПРОЕКТ. Физические Q/K1/SB2/ЩАО/МЭ210 не трогать; новых `.owle` и PASS-SIM V2 нет; T35/P04-02 остаются FAIL-SIM.
