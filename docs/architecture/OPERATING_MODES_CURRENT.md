# Режимы ПР103 V2 — актуальная таблица поведения (12.11.2026)

**Статус:** дизайн для согласования. Согласована только принципиальная необходимость ручного возврата после ремонта оптики (D-02); детали ниже, помеченные OPEN, не утверждены. `STOP_REQUEST` — логическая команда, не выход Q/К1 и не факт отсутствия напряжения.

| Режим | Вход | STOP_REQUEST | Выход / условия |
|---|---|---|---|
| `INIT_UNTRUSTED` | После каждого старта/перезапуска ПР103 | Консервативно 1 в логической SIM-модели | Только по согласованной процедуре установления доверия и санкции; немедленный REMOTE по старому STOP=0 запрещён |
| `REMOTE` | Санкционированный нормальный режим при непрерывно доверенном обмене, LOCK=0 | SB1=1 → 1; SB1=0 → 0 только при достоверных текущих данных | При обнаруженной потере доверия → `LOSS_LOCK` |
| `LOSS_LOCK` | Обрыв/старение данных, нарушение доверия, неудачный возврат | 1 | Только новая санкционированная SB3 с выполненным регламентом → LOCAL; альтернативные способы сброса OPEN |
| `LOCAL` | Санкционированное местное разрешение при нарушенной оптике | Допускается временное подавление команды системы и старой SB1; результат 0 *лишь* в рамках разрешённого LOCAL | При ремонте оптики **остаётся LOCAL до нового действия персонала**; запрос возврата и свежая SB1 проверяются совместно, детали OPEN |
| `RECOVERY_WAIT` | **Только после нового санкционированного действия возврата**, при пригодной восстановленной связи; вход по одному HB/Modbus OK запрещён | Не менять разрешение автоматически; выходной STOP определяется утверждаемым приоритетом текущей SB1 и LOCK | `REMOTE` только после проверки текущей SB1, устойчивости, снятия санкции LOCAL и всех условий; при ошибке/обрыве реакция OPEN |

## Запрещённые переходы

- `LOCAL + Modbus OK + новый HB + старый STOP=0` **не** даёт ни `RECOVERY_WAIT`, ни `REMOTE`, ни `RESET LOCK` (исторический T35 FAIL-SIM).
- Удержание SB3 при запуске не трактуется как новое разрешение. Нужна проверяемая логика отпускания и нового нажатия (D-03).
- При рестарте ПР205/ПР103, повторе старого N/ACK и переполнении счётчика нельзя использовать неподтверждённый STOP=0 для снятия защиты (P04-02 FAIL-SIM).
- Новая достоверная SB1=1 при восстановлении должна иметь приоритет STOP по ТЗ §3.9; способ смены самого режима OPEN.
- Изменения SB1 на КПП при оборванной оптике ПР103 не получает; LOCAL требует соответствующей процедуры персонала и независимой SB2.

## Новый согласованный сценарий

1. Оптика оборвана; после санкции SB3 действует LOCAL.
2. Оптику отремонтировали; обновились Modbus/HB; **LOCAL сохраняется**.
3. Персонал выполняет **новое сознательное действие**; его физический источник пока не утверждён (предложена повторная SB3).
4. Проверяются устойчивость канала и **актуальное** состояние SB1; требования к проверке D-01/D-04 открыты.
5. Только после выполненных условий завершить местное разрешение и вернуться в REMOTE; никакого автоматического пуска из факта STOP=0 не следует.
