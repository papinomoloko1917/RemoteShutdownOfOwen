# Реестр решений V2 — 12.11.2026

**Статус `D-02`: принято поведение, не реализация.** После ремонта оптики остаёмся в санкционированном LOCAL до нового сознательного действия персонала и проверки актуальной SB1; `Modbus OK`, HB и старый STOP=0 не сбрасывают LOCAL/LOCK. Ссылка: согласование в переписке 12.11.2026, ТЗ ред. 6 §3.9. Исторический T35 остаётся FAIL-SIM.

| ID | Статус | Решение / вопрос до FBD |
|---|---|---|
| D-01 | OPEN | Критерий достоверности текущей SB1 при непрерывном REMOTE и после обрыва; не обещать полную защиту от скрытого перезапуска по одному HB |
| D-02 | **APPROVED / BEHAVIOR ONLY** | Возврат из LOCAL после ремонта оптики **вручную**; сама связь не инициирует возврат |
| D-03 | OPEN | Чем выражается действие возврата — повторная существующая SB3 или другой утверждённый способ; учесть удержание SB3 при старте и защиту от двойного действия |
| D-04 | OPEN | Перезапуски обоих ПР, повтор старого STOP/N/ACK, переполнение, недоступность Retain; не применять недоказанную свежесть |
| D-05 | OPEN, HW | Выход Q, K1 и физическое поведение ЩАО при потере питания ПР103 — не выбирать без рабочей схемы |
| D-06 | OPEN | ТЗ ред. 6 ссылается на СДУО-СС-01 ред. 2, в Git присутствует ред. 1 |
| D-07 | OPEN | Фактические прошивки ПР103/ПР205, совместимость группировки FC03 |
| D-08 | OPEN | SFP/потери оптики/питание КСН210, отсутствие резерва оптической линии |
| D-09 | OPEN | Точки A/B/C/N после АВР, напряжения/пороги/выдержки и UNKNOWN МЭ210 |
| D-10 | OPEN | ПР103 `.03.1.0`, УГО лист 3; EPLAN `.03.2.0` — другое исполнение |
| D-11 | OPEN | HL1–HL4 и диагностические приоритеты |
| D-12 | OPEN | Ошибки чтения/многословные данные/старые значения/Retain |
