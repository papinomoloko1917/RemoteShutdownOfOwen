# V2 — актуальные архитектурные границы (12.11.2026)

**DESIGN / NOT IMPLEMENTED / SIM_ONLY.** Это инженерная спецификация, а не утверждённая безопасная система.

## Аппаратные узлы

1. **КПП / ПР205-24.1211.02.0.0:** вход SB1, диагностический кадр и Slave Modbus TCP. Из старого V1 известны регистры 16384 STOP, 16385 HB, 16389 кадр `2×HB+STOP`; они не доказывают свежесть после рестарта. Экспериментальный challenge/ACK 16390/16391 в V2 автоматически не переносится.
2. **КСН210-2.1 × 2:** связь через SFP и существующую оптику. Bypass коммутатора касается только медных Ethernet 1/2, не резервирует SFP (РЭ КСН210-2.1, стр. 1–2).
3. **ПР103-24.1610.03.1.0:** Modbus TCP Master, отдельные уровни диагностики связи/данных, разрешений, автомата режимов и абстрактной `STOP_REQUEST`; никаких физических Q/K1.
4. **МЭ210-701:** отдельное Modbus TCP Slave для фаз A/B/C и диагностической маски. РЭ v1.41, §6.5.1, стр. 28–31; §6.6.10, стр. 45. Контроль напряжения **не** выдаёт разрешение очистить STOP/LOCK/LOCAL.
5. **Действующий ЩАО/АВР/ДГУ, SB2 и K1:** не изменять; тип и полярность K1, схема ЩАО и реакция на пропадание питания ПР103 пока не утверждены. Положение команды `STOP_REQUEST` не равно фактическому напряжению.

## Принципиальное изменение D-02

После ремонта оптики санкционированный LOCAL должен оставаться активным, пока не выполнено новое сознательное действие персонала. Никакая восстановившаяся связь, новый HB или старый STOP=0 не сбрасывают блокировку. Действительное состояние SB1 обязательно проверяется до возврата. Использование существующей SB3 повторно — **предложение**, D-03 OPEN.

## Защитные границы

- `KPP_MODBUS_OK != SB1_DATA_VALID != RELEASE_PERMISSION`.
- В REMOTE SB1=1 формирует STOP, SB1=0 при непрерывно доверенном канале и отсутствии LOCK снимает обычную команду по ТЗ §3.3; критерий доверия D-01 OPEN.
- При обнаруженной потере доверия установить защитный LOCK. В санкционированном LOCAL его можно временно подавлять, но нельзя автоматически стирать.
- Даже при свежем SB1=0 после LOCAL требуется санкция возврата. При свежей SB1=1 приоритет STOP определяется ТЗ §3.9; точное переключение режимов ещё OPEN.
- Проверки МЭ210 и HL2 — только технологическая индикация по трём фазам, не проверка отсутствия опасного напряжения для допуска к работам.
