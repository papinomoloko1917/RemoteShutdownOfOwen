# Modbus и достоверность SB1 — V2 (12.11.2026)

## Документировано ОВЕН

«Owen Logic (версия 3.3). Руководство пользователя» v2.12, 09.2026, §5.3.2, стр. 111–113 и §5.3.2.1, стр. 121–123:

- ПР103 и ПР205 относятся ко второму поколению и поддерживают Modbus TCP Master/Slave.
- Master поддерживает запросы по таймеру и чтение по команде булевой переменной; в его настройках есть статус устройства, разрешение опроса, таймаут и число попыток.
- Штатная диагностика Master второго поколения — на уровне **устройства** (есть связь или нет); отдельный статус завершения каждой операции, подобный первому поколению, в приведённой таблице не указан.
- Последовательно обслуживаются устройства и запросы; группировка до 16 регистров при поддержке прошивок не делает разные запросы атомарным снимком.
- Руководство ОВЕН не утверждает, что одно успешное чтение или обновившийся HB доказывает текущую SB1 после незамеченного перезапуска ПР205.

## Исторический V1 — не переносить автоматически

ПР205 Slave DEC 16384 STOP, 16385 HB, 16389 `2×HB+STOP` (диагностика), 16390 CHALLENGE, 16391 ACK. Прототип ПР103 не реализовал FC06/FC03 для 16390/16391; `KPP_SB1_FRESH_CONFIRMED` не формировалась. P03 7/7 и P04-01 5/5 PASS-SIM — только локальная фиксация ACK. P04-02 FAIL-SIM — повтор старого номера 4 после restart симуляции снова принят; это не доказательство физического replay.

## Инженерное требование к V2

`DEVICE_COMM_OK`, `SB1_DATA_VALID`, `SB1_FRESH_FOR_RELEASE` и `RELEASE_AUTHORIZED` — разные признаки. В непрерывном REMOTE допускается штатное отпускание SB1 по ТЗ §3.3 только при согласованной и проверенной достоверности; после известной потери связи защитный LOCK не снимается ни по Modbus OK, ни по HB, ни по старому STOP=0. После ремонта оптики, даже при положительной проверке SB1=0, нужен новый акт персонала (D-02).

**Открытый D-01/D-04:** без механизма обнаружения всех существенных рестартов и повторов нельзя гарантировать полную свежесть. Решение `A` с ручным возвратом не нужно представлять как полную эквивалентность защищённому сессионному протоколу `B`.

## Отдельный МЭ210-701

Modbus TCP Slave МЭ210 — другой узел с независимой картой. РЭ МЭ210-701 v1.41, §6.5.1, табл. 6.5, стр. 30–31: FLOAT32 A/B/C DEC 5240/5242/5244 по 2 регистра; UINT32 маска DEC 5340, 2 регистра. §6.6.10, стр. 45: биты 1–3 отсутствия напряжения без численного порога в источнике. Предлагаемые FC03 5240/6 и 5340/2 — ещё не проверенная конфигурация. При недействительности показаний — UNKNOWN. На STOP/LOCAL/LOCK не влияет.
