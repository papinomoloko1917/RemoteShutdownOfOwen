- `apply_docs_update.py` — автономный скрипт, создающий **полные обновлённые Markdown-файлы** из существующей локальной копии репозитория или изменяющий их локально по явному флагу. Используется только стандартная библиотека Python; скрипт не обращается к GitHub и не вызывает `git`.
- `references/owen/manuals/rp_owen_logic.pdf` — **неизменённый оригинал** официального «Owen Logic (версия 3.3). Руководство пользователя», 09.2026, версия 2.12, 325 страниц, предоставленный пользователем. Его не нужно присылать в чат повторно. SHA256: `858992870bf8b39729468e9213e5f5fc39d9d9f0423991363073375b4d110f7a`.
- `UPDATE_SUMMARY.md` — перечень решений/ограничений и затронутых документов.

## Безопасное применение к вашей локальной копии

1. Сохраните/распакуйте пакет **вне** каталога клона репозитория.
2. Убедитесь, что в локальном клоне находятся оригинальные документы `main` на указанном коммите. Если в документах есть ваши более свежие изменения, **не запускайте применение**, а сначала сравните их.
3. Предпочтительно сначала создать новую папку с **готовыми полными обновлёнными файлами**, не трогая оригиналы:

   ```powershell
   py .\apply_docs_update.py --repo "C:\путь\RemoteShutdownOfOwen" --output "C:\путь\RemoteShutdownOfOwen_V2_updated"
   ```

   Скрипт создаст в выходной папке 12 Markdown-файлов с исходными путями плюс `references/owen/manuals/rp_owen_logic.pdf`. Проверьте различия и затем перенесите выбранные файлы в локальный репозиторий самостоятельно.

4. Если вы хотите внести исправления **сразу в локальный клон** (без commit/push), используйте явный режим:

   ```powershell
   py .\apply_docs_update.py --repo "C:\путь\RemoteShutdownOfOwen" --in-place
   ```

   **Ни одна команда не делает `git add`, `git commit`, `git push`.** Меняются только перечисленные Markdown и добавляется неизменённый PDF; `.owle`, результаты тестов, физические выходы не затрагиваются.

5. Для получения отдельного diff на проверку (без изменений источника):

   ```powershell
   py .\apply_docs_update.py --repo "C:\путь\RemoteShutdownOfOwen" --patch "C:\путь\V2_docs_update.patch"
   ```

## Принципиальные ограничения

- **СОГЛАСОВАНО D-02:** после ремонта оптики ПР103 остаётся в разрешённом LOCAL до нового сознательного действия персонала; перед возвратом проверяется актуальная SB1.
- **НЕ СОГЛАСОВАНО D-03:** как именно используется существующая SB3 для возврата; повторное нажатие — предложение, не решение.
- **ОТКРЫТЫ D-01/D-04:** строгая свежесть SB1, особенно при незамеченном рестарте ПР205 и replay. Owen Logic Modbus Master `Статус` подтверждает состояние устройства, не свежесть каждого STOP=0.
- Не начинать FBD/`.owle`, не задействовать K1, SB2, ЩАО, МЭ210, физические Q. T35/P04-02 остаются `FAIL-SIM`; новых PASS-SIM V2 нет.

## Почему пакет в форме локального обновления

Подключённый GitHub был использован **только для чтения** и сверки исходных Git blob. Для сохранения большого исторического журнала (§§1–22) и старых редакций checkpoint без переписывания и потери текста изменения реализованы точными добавлениями/заменами с проверкой исходных хэшей. Скрипт работает офлайн на **вашем** checkout и создаёт полные итоговые файлы для проверки. Удалённый репозиторий этим пакетом не изменяется.
